Real GitHub data

RepoScope calls the GitHub REST API to load a profile and its public repositories. It follows repository pages and calculates the overview in your browser.

Clear boundaries

Original repositories are shown by default; you can include forks. Stars are attention signals, not a measure of engineering ability. Archived projects are labelled.

Your browser, your session

No backend, analytics, tokens or permanent storage. GitHub receives API requests, including your IP address. Unauthenticated requests share GitHub’s network rate limit.
